Get started

Install and set up

Install the desktop app, open it the first time, and set up your lab.

Get it

macOSDownload, unzip, drag BioManager into Applications. The first time, right-click it → Open, then Open.
WindowsExtract the zip, open the BioManager folder, run BioManager.exe. At the warning choose More info → Run anyway. Its window uses Microsoft Edge WebView2, which Windows 11 has; on a Windows 10 PC without it, BioManager offers to download it from Microsoft and opens in your web browser meanwhile. Install it, then open BioManager again for its own window.
LinuxMark BioManager-Linux.AppImage executable (right-click → Properties, or chmod +x) and open it.
UpdatesThe desktop app checks for a new version once a day and offers it, with what's new; BioManager → Check for Updates… (on Windows and Linux, Help) asks now. Install and Restart downloads it, checks it, and swaps it in as the app quits; where it can't (the Linux .tar.gz, a folder it can't write to), it opens the download to install as above. Your data stays where it is, and before a new version changes it a copy is kept (Your data). Turn the daily check off with Check for Updates Automatically.
What's newAfter an update, on a desktop or a lab server, the first page you open shows a short What's new: what is new, what works differently and what was fixed, with a link to the full notes. Got it closes it for good; Help → What's new opens it again.
A lab serverNothing to install: open the address your admin gives you. It opens on your lab's sign-in, with its name and what it keeps; new to the lab, choose Ask to join. Setting one up is on Run it for your lab.
Updating a lab serverThe server looks for a new version once a day and tells its admins. They find it in Settings → Devices & copies → Updates, with what's new and a link to the release notes. Update now takes a backup, installs the new version and restarts the server; BioManager is away for a minute or two, and the page comes back by itself on the new version. The phone apps open the server, so they follow it. Turn the daily look off with Check for new versions every day.
PhonesThe Android app, or your lab server added to an iPhone's home screen: see Phones and cage cards.
Why the warning on a computer? The apps aren't signed by Apple or Microsoft, so the system asks you to confirm once per version.

Starting a lab

The first time the desktop app opens, it asks Does your lab already use BioManager? Yes, open my lab takes the lab's address and opens it in this window from then on; nothing is made on the computer. No, start a new lab makes a new, empty lab, and says so: you name it, choose whether it lives on this computer or a lab server, and make its first account, which is the lab's admin. A server nobody has set up says it has no lab yet, and starts the same way, with the one-time setup code printed when the server started. The admin then answers a short survey, and BioManager builds exactly what you'll use — nothing more:

  1. Your lab — its name, time zone, how dates are written and the genotyping day (what these do).
  2. What does your lab keep? Tick animals and stocks (mice, zebrafish, flies, worms, other organisms) and molecular and supplies (plasmids, samples, orders, reagents, chemicals, antibodies, viruses). For each, a little more: a name (e.g. Mouse room B); for the colony how many racks, their size and how positions are labelled; for flies and worms which incubator temperatures you run. Blank means the usual.
  3. Which lab functions? The calendar and the notebook.
  4. What may members do? Whether members may create databases of their own, whether they may add databases for the whole lab, whether they may keep a copy of the lab on their computers, and whether they may make API tokens.

Below the questions, Send BioManager's makers anonymous counts once a day is ticked; untick it if you'd rather not (what is sent).

BioManager then makes those databases, the racks and incubators too, and shows the lab ready, with the address people join at. Everyone who joins later gets a one-page welcome tour of the lab's databases on first sign-in (Settings → Your data → See the welcome tour again brings it back).

English or 中文. BioManager shows in the language your computer or browser asks for first, English or Simplified Chinese; the desktop app follows your computer's. Choose for yourself under Settings → Appearance & language, which changes as soon as you pick, or with the 中文 / English switch on the sign-in page, which then stays your choice when you sign in. Everyone in the lab chooses their own; names, notes and everything people type stay as written.

Easier to read. Text is set in Inter, which tells I, l and 1 apart in IDs and genotypes, with your computer's own Chinese font. Settings → Appearance & language → Font switches to the computer's font instead (SF Pro on a Mac, Segoe UI on Windows). Text size there makes everything smaller or larger in the Mac app; in a browser, its zoom does the same (⌘ + and ⌘ −, or Ctrl on Windows).

Troubleshooting

The app won't open on my Mac

Right-click it and choose Open. If macOS says it's damaged, move it to Applications first, then try again.

Linux: the AppImage does nothing

Mark it executable. If it still won't start, install libfuse2, or use the .tar.gz and run BioManager/BioManager.
