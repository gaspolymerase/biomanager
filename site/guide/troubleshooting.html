Troubleshooting

Common problems and their fixes, each also on the page it belongs to.

The app won't open on my Mac
Right-click it and choose Open. If macOS says it's damaged, move it to Applications first, then try again. → See the page
Linux: the AppImage does nothing
Mark it executable. If it still won't start, install libfuse2, or use the .tar.gz and run BioManager/BioManager. → See the page
My phone can't reach the server
Check the address with your admin; that you're on the lab's network, VPN or Tailscale; and, if your lab uses its own certificate, that it's installed on the phone. → See the page
I can't edit a record
It belongs to someone else and isn't shared: BioManager says whose it is. Ask them, or an admin. → See the page
A cell turned red
That change wasn't saved; the message at the bottom says why (a required field, a date that isn't one). → See the page
I made a mistake with a bulk change
More → Batch history in the sidebar → Undo. → See the page
I forgot my password
Ask an admin: Manage users resets it. → See the page
Rows were skipped on import
The preview lists each one by its row number in Excel and says why. Fix those rows and import just them: importing the whole sheet again would add the other rows a second time. → See the page
A colleague's database isn't in my sidebar
It may be their personal one (Just you on its tile), which only they and admins see, or an admin may have switched it off. → See the page
A database disappeared from the sidebar
An admin may have switched it off in Lab setup; its data is kept, and it comes back when it is switched on. → See the page
Something else
Help → Send feedback in the sidebar (see below), or open an issue — say which system you use and what you expected to happen.
