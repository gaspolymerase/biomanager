macOS：右键 → 打开，再点“打开”。Windows：更多信息 → 仍要运行。系统只问这一次，因为本应用没有 Apple 或 Microsoft 的签名。

常见问题

先了解一下。

数据存在哪里？

存在你的电脑上、应用之外，所以更新或重装都碰不到它：macOS 在 ~/Library/Application Support/Biomanager/，Windows 在 %APPDATA%\Biomanager\， Linux 在 ~/.local/share/Biomanager/。随时可以在“设置 → 导出我的数据” 把全部记录打包成一个 zip 下载下来。

数据库能放在 Dropbox、OneDrive 或 iCloud 里吗？

请不要。数据库文件写到一半时被同步，就会损坏。BioManager 发现自己在同步文件夹里时 会提醒你。全实验室一起用的话，请改用服务器，大家可以同时使用。

全实验室都能用吗？

可以，用实验室服务器：你们局域网里的一台实验室电脑、学校的虚拟机，或者配合 Tailscale 的免费云服务器。 新注册的账号要等管理员批准；每人编辑自己负责的记录，共享的笼归笼里各只动物的负责人共同管理， 每次修改都有记录。所有方案、费用和步骤。

数据安全吗？

服务器每晚备份，每周把最新的备份恢复一次，确认它真能用；还可以在异地和你自己的电脑上保存 加密副本。批量修改可以撤销，每次编辑都记在 修改记录里。副本怎么保存。

有手机应用吗？

有，配合实验室服务器使用：Android 应用全屏打开你们实验室的服务器，还能扫笼卡。在 iPhone 或 iPad 上，用 Safari 打开服务器，点 共享 → 添加到主屏幕：它会有自己的图标， 像应用一样全屏打开。桌面版只装在一台电脑上，数据也只在那台电脑里，手机 连不上。

Linux：AppImage 打不开。

先给它加上可执行权限（右键 → 属性 → 允许执行，或者运行 chmod +x BioManager-Linux.AppImage）。 还是打不开的话，可能是系统缺少 FUSE：安装 libfuse2，或者改用 .tar.gz，运行 BioManager/BioManager。

Windows：打开时弹出报错，BioManager 没有启动。

如果看到 Unhandled exception in script、Failed to load Python DLL 或 'gbk' codec can't decode 之类的提示，通常是下面几种情况之一：

  • 在压缩包里直接打开了。先关掉，右键点 zip →“全部解压缩”，再打开解压出来的文件夹里的 BioManager.exe。
  • 在中文（或日文、韩文）Windows 上用的是 1.0.5 或更早的版本。这些版本在这类系统上无法启动。请在上面下载最新版本：从没打开过的旧版本没法自己提示更新。
  • 杀毒软件删掉了部分文件（360、火绒等有时会这样，因为本应用没有签名）。在杀毒软件里把 BioManager 设为信任，再重新解压一次。

还是不行？在 GitHub 上提个问题，附上报错窗口的截图。

Windows 10：BioManager 在网页浏览器里打开了。

BioManager 的窗口要用到 Microsoft Edge WebView2。这是 Windows 的免费组件，Windows 11 自带，部分 Windows 10 电脑 没有。BioManager 会提示从 Microsoft 下载（选“是”），在此之前先在浏览器里运行；使用期间请不要关掉它的 提示窗口。装好 WebView2 后重新打开 BioManager，就有自己的窗口了。

为什么第一次打开时系统会弹出警告？

BioManager 没有用 Apple 或 Microsoft 的开发者证书签名，所以系统会让你 确认一次。Mac 上，右键点应用，选“打开”；Windows 上，选“更多信息”，再选“仍要运行”。

除了小鼠，还能管别的物种吗？

斑马鱼、果蝇和线虫各有自己的模块。其他物种可以用添加数据库 来描述：怎么称呼、怎么计数、需要哪些功能，完全不用写代码。

它和 R 包 BiocManager 有关系吗？

没有。BiocManager 是 Bioconductor 用来安装 R 包的工具。BioManager 是另一个独立的应用，用来管 实验室：动物、品系、物资、日历和实验记录本。用它不需要装 R。

真的免费吗？

是的。BioManager 以 MIT 许可证发布：可以自由使用、分享和修改。
