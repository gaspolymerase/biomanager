怎么做

连接 AI 助手

按助手应用逐一说明：添加一次 BioManager 插件，把它连接到你的实验室，登录，然后试一试。

实验室服务器或桌面版

连接只需几分钟，做一次就好。不管用哪个应用，都是同样的四步：

  1. 确认你的应用能连上 BioManager（见下表）。
  2. 添加 BioManager 插件（如果你的应用支持插件）。它教助手怎么使用 BioManager，你就不必再解释。
  3. 用你的 BioManager 地址把它连接到实验室，然后 登录：BioManager 会在浏览器里打开，按 允许。 不需要把密码或令牌交给助手。
  4. 试一试：说 我想在 BioManager 里改点东西。

需要的一切都在 BioManager 的 帮助 → 连接 AI 助手 里（也在 设置 → AI 助手与令牌 里），你的实验室地址 已经填好，有些应用有按钮，其他的有可以复制的命令。把它和这一页并排打开。

你的应用能连上 BioManager 吗？

助手应用要么从你自己的电脑连接，要么从它公司在互联网上的服务器连接。这决定了它能连上什么：

你的 BioManager电脑上的应用云端的应用
桌面版，就在这台电脑上可以不行
实验室服务器，只在实验室网络里可以，从实验室网络里的电脑不行
在互联网上的实验室服务器可以可以
  • 电脑上的应用：Claude Code、Codex、Cursor、VS Code、Cherry Studio、千问办公（QwenWork）、Trae、电脑版豆包、 Qwen Code、Kimi Code，以及用令牌的 Claude Desktop。
  • 云端的应用：claude.ai（包括 Claude 桌面和手机应用里的对话）和 ChatGPT。它们需要实验室服务器在互联网上， 由管理员打开（见服务器手册里的 互联网访问）。在那之前，连接页面会说明这一点，只列出其他方式。

连接页面会显示两个地址，都以 /api/v1/mcp 结尾：连接器地址（在互联网上，给云端应用用）和 这台电脑或实验室网络 上的应用用的地址。

Claude

网页版、桌面应用和手机上的 Claude

需要实验室服务器在互联网上。在 claude.ai 或桌面应用里设置，手机应用随后也就有了。

  1. 添加插件。 打开 Customize → Plugins，选 Add → Add marketplace，输入 gaspolymerase/biomanager，再打开 BioManager，按 Add。等 BioManager 上架 Claude 的插件目录后，也可以直接在 Discover 里找到它。也可以从 下载页 下载 Claude 插件，选 Add → Upload plugin 上传这个 zip。
  2. 添加连接器。 打开插件的 Connectors 标签（或 Customize → Connectors），选 Add custom connector，名字填 BioManager，粘贴连接页面上的 连接器地址。
  3. 连接。 按 Connect。会打开一个 BioManager 页面，要你输入 连接码。在连接页面（在实验室网络里） 按 获取连接码，输进去，再按 允许。连接码只能用一次，10 分钟内有效。
  4. 试一试。 新开一个对话，确认对话的工具菜单里 BioManager 已打开，然后说 我想在 BioManager 里改点东西。 第一次它每用一个工具都会先问你；对 BioManager 的工具选 Always allow。这些工具只能读取和提议： 在你于 BioManager 里批准之前，什么都不会改变。
Team 或 Enterprise 套餐 由所有者为整个组织添加连接器，也可以给所有人装好插件 （Installed by default）。之后每个人只需用自己的连接码连接一次，助手就以本人的身份工作。

Claude Code

可以连桌面版，也可以连实验室网络里的服务器。在 Claude Code 里：

  1. 输入 /plugin marketplace add gaspolymerase/biomanager，再输入 /plugin install biomanager@biomanager。
  2. 它会问 BioManager's MCP address：粘贴连接页面上 这台电脑或实验室网络 用的地址。
  3. 输入 /mcp，选 biomanager，再选 Authenticate。BioManager 会在浏览器里打开：按 允许。
  4. 说 我想在 BioManager 里改点东西。

不装插件的话，用连接页面上的那一条命令连接（claude mcp add …），或者按 复制这段话 发给 Claude Code，它会自己设置好。

Claude Desktop 连接桌面版或实验室网络里的服务器

Claude Desktop 自己的连接器走互联网，所以连不上的 BioManager，要改用 BioManager 源代码里的一个小程序。在连接页面按 生成令牌：下一页会给出粘贴到 Claude Desktop（Settings → Developer → Edit Config）的设置，地址和令牌都已填好。 具体步骤，以及安装所需依赖的那一条命令，在 mcp/README.md 里。Claude Desktop 的 Code 标签就是 Claude Code，按上面的方法连接。

ChatGPT 和 Codex

ChatGPT

需要实验室服务器在互联网上，并且要用网页版 ChatGPT：ChatGPT 的手机应用不能添加你自己的服务器。ChatGPT 只允许 Business、Enterprise 或 Edu 工作区这样修改记录，且要由管理员打开开发者模式；其他套餐只能读取。

  1. 打开 Plugins，按 +，选 Add custom MCP server。
  2. 名字填 BioManager，粘贴 连接器地址，选 OAuth，按 I understand and want to continue 确认，然后 Create as a plugin 并安装。
  3. 要求登录时，会有一个 BioManager 页面要你输入 连接码：在连接页面获取一个，输进去，按 允许。
  4. 想让 ChatGPT 不用解释就会用 BioManager，再加上插件：从 下载页 下载 ChatGPT 插件， 在 platform.openai.com/plugins 上传，再分享给实验室成员，每个人安装即可。如果实验室里已经有人分享给你，直接安装就行。
  5. 在对话里选择 BioManager（输入 @），说 我想在 BioManager 里改点东西。在它的权限里选 Allow read actions，它就不会每次查找前都问你。

Codex

  1. 添加插件：codex plugin marketplace add gaspolymerase/biomanager，然后在它的插件里安装 BioManager。
  2. 连接：codex mcp add biomanager --url <地址>，用 这台电脑或实验室网络 的地址（连接页面上有 填好地址的命令）。
  3. 登录：codex mcp login biomanager。BioManager 会在浏览器里打开：按 允许。

Cursor 和 VS Code

  1. 在连接页面按 添加到 Cursor 或 添加到 VS Code。应用会打开，并在添加 BioManager 前先问你：同意即可。
  2. 登录：应用会显示 BioManager needs login，或请你允许；BioManager 会在浏览器里打开，按 允许。
  3. 在 VS Code 里还要添加插件：运行 Chat: Install Plugin From Source，填 https://github.com/gaspolymerase/biomanager。

国内常用的助手

DeepSeek、千问和 Kimi 的聊天应用目前还不能连接其他应用。下面这些可以，在能连上 BioManager 的电脑上使用。

Cherry Studio，配 DeepSeek、千问、Kimi 或 GLM

  1. 按 Cherry Studio 的说明，用你的模型密钥（DeepSeek、千问、Kimi 或智谱 GLM）设置好 Cherry Studio。
  2. 在连接页面按 添加到 Cherry Studio。Cherry Studio 会打开，BioManager 已经加上但处于关闭状态：在 设置 → MCP 里把它打开。
  3. BioManager 在浏览器里打开时登录：按 允许。
  4. 在对话里打开 BioManager 的工具，说 我想在 BioManager 里改点东西。

千问办公、Trae 和豆包

这些应用用你的 BioManager 地址加一个令牌连接。在连接页面按 生成令牌；下一页会给出设置，地址和令牌都已填好。

  • 千问办公：扩展 → 连接器 → + 添加 → 粘贴 JSON 配置，粘贴那段 JSON。
  • Trae：设置 → MCP → 添加 → 手动添加，粘贴同一段 JSON。
  • 电脑版 豆包：技能 · 连接器 → 新建 → 新建自定义连接器，传输类型选 HTTP，填地址，再加一个请求头 Authorization，值为 Bearer 加空格和令牌。

令牌只显示一次：保存在应用里，不要记在笔记里。不再使用这个应用时，到 设置 → AI 助手与令牌 撤销它。

Qwen Code 和 Kimi Code

  • Qwen Code：用 qwen extensions install https://github.com/gaspolymerase/biomanager:biomanager 添加插件，再用 qwen mcp add --transport http biomanager <地址> 连接。它会自己在浏览器里登录。
  • Kimi Code：用 /plugins install https://github.com/gaspolymerase/biomanager/releases/latest/download/BioManager-plugin-Kimi.zip 添加插件，它问时确认。然后输入 /mcp-config，添加一个名为 biomanager 的 HTTP 服务器，填入地址（或在 ~/.kimi-code/mcp.json 里写 {"mcpServers": {"biomanager": {"url": "<地址>"}}}）。用 /mcp-config login biomanager 登录：BioManager 会在浏览器里打开：按 允许。再输入 /new，说 我想在 BioManager 里改点东西。插件里的提示词在 /biomanager: 下，比如 /biomanager:log-today。
  • 旧版 kimi-cli 不支持插件：用 kimi mcp add -t http biomanager <地址> --auth oauth 连接，然后 kimi mcp auth biomanager。

用 DeepSeek 或 GLM 运行 Claude Code

DeepSeek 和智谱（GLM）都提供兼容 Claude API 的地址，所以 Claude Code（以及 BioManager 插件）可以用 DeepSeek 或智谱的 密钥运行。按它们自己的说明设置 Claude Code（DeepSeek 的 Anthropic API 指南、智谱的 Claude Code 指南）， 然后按上面的 Claude Code 操作。

其他应用

支持 MCP 服务器的其他应用（Goose、OpenCode、LobeHub、Chatbox 等）需要这个地址，类型选 streamable HTTP。 如果它支持 OAuth 登录，请求头留空，在浏览器里登录；如果不支持，按 生成令牌，把下一页给出的请求头填进去。 只能启动命令的应用，像 Claude Desktop 那样运行 mcp/biomanager_mcp.py。

确认连好了

  1. 说 我想在 BioManager 里改点东西。它应该列出今天的待办，问你做了什么，而不是问你 BioManager 怎么用。
  2. 告诉它一件真实的小事，比如 称了 1043 号小鼠，24.1 克。它会找到这只小鼠，发一个提议，并给你一个链接。
  3. 在 BioManager 里打开这个链接（或点铃铛）：提议在 修改提议 里等你。看一遍，按 批准 或 丢弃。

这个连接会以应用的名字列在 设置 → AI 助手与令牌 里。在那里撤销就能断开，助手之后什么都读不到。

疑难解答

助手好像不认识 BioManager

确认对话的工具里 BioManager 是打开的（Claude、ChatGPT、Cherry Studio 每个对话单独开关工具），并且插件已添加、已启用。 没有插件时，说 先用 BioManager 的 lab_overview。

它连不上 BioManager

电脑上的应用：确认 BioManager 正在运行，地址用的是 这台电脑或实验室网络 的那个。claude.ai 和 ChatGPT：连接器地址 应该能用不连实验室 Wi-Fi 的手机打开，显示一句要 API 令牌的提示。如果打不开，说明服务器还没有上互联网。

连接时说连接码不对

连接码只能用一次，10 分钟内有效。再按一次 获取连接码，用新的那个。

ChatGPT 能读取但不能提议

Business、Enterprise 和 Edu 以外的 ChatGPT 套餐，对你自己的服务器只能读取。用别的应用来提议，或者问你工作区的管理员 能否打开开发者模式。

过几周又要我重新登录

登录在 90 天不用后失效。用同样的方法再登录一次即可，其他什么都不会丢。
