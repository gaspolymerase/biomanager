数据库

质粒

质粒记录、序列和图谱，以及每管所在的冻存盒。

它对你的克隆工作意味着什么

一个构建体的价值，取决于一年以后你还能不能说清楚它：它由什么拼出来、用的是哪些引物、 冻存盒里哪一管才是对的，以及文件里的序列和管子里的序列是不是同一个。 这些页面把整个闭环放在一处，而不是散在 SnapGene 文件、引物表格和一张冻存盒示意图之间。

设计组装质粒 用你已有的质粒拼出下一个——酶切连接、Gibson 或 Golden Gate—— 产物会记下它由什么构建而来，于是一年后回答这个问题的是家族树，而不是你的记忆。
需要的引物向导设计的引物，以及你自己在图谱上画的引物，都会进入实验室的 引物 数据库， 状态是待订购，旁边写着对应的质粒。勾选后用 复制以订购，就能把清单交给公司。
验证拿到的东西识别特征 会在新图谱上标出实验室已知的元件； 验证这个克隆的测序结果就存在质粒自己的 文件 里，跑胶照片也在。
找到那一管每个质粒都有冻存盒位置，带着它的细菌在 甘油菌 里，也有自己的盒位—— 于是「哪一管」有确定答案，而不是同事的印象。
交给别人用它制备的病毒会写明来源质粒；质粒页面也列出由它制备的东西。 外面的人要的时候，随时导出 GenBank。

你不用再做的事：图谱放一个文件夹、引物放另一个表格；为了订购把引物重敲一遍； 猜哪一管小提是好的；以及做这个构建体的人一走，它由什么拼出来的就没人知道了。

  • 页面顶部是与质粒相关的数据库标签页——引物、甘油菌、病毒——按实验流程排列。 每一个都是普通的数据库，有自己的表格（查看）； 它们在侧边栏合用一个位置 分子生物学（实验室还没有这几个数据库时就叫 质粒），因为每一条记录都写明了来源质粒。

质粒表格

  • 可以显示为 表格 （Table）、按存放的 冻存盒 （Boxes）显示，或显示为 列表 （List）；筛选标签有 我的（Mine）、有序列（Has sequence）、在盒中（In a box）。
  • 表格中每个质粒编号旁边的 序列 （Sequence）会打开它的序列和图谱（还没有序列时显示 添加序列 （Add sequence））； 点编号也会打开同一页面。
  • 新建质粒 （New plasmid）填写名称、骨架、插入片段、抗性、负责人和冻存盒位置（留空则取下一个空位）—— 也可以粘贴一份名字列表一次建多个。可以拖入 SnapGene .dna、GenBank、FASTA 或纯文本序列：名称、特征和所有注释说明都会一起导入； 一个文件里有多条序列时，只保留第一条并会提示。

序列与图谱

  • 打开一个质粒，可以在可交互、可编辑的图谱上查看它的序列和特征（编辑会自动保存），还可以 全屏。图谱上方的 下载 可以导出 GenBank（含所有特征）或 FASTA。图谱下方的 版本 列出以前的每一版序列（被替换、清空或编辑过的），可以 恢复。另外两个标签页是 存放 （Storage）和 属性 （Properties）。 在 属性 里，来源质粒 记录它的骨架、插入片段或模板（实验室里的质粒，填编号或名称；或外来的，如 Addgene #11150） 以及构建方法；之后页面在图谱上方显示 来源质粒 和 用于制备，并有双向的 家族树。存放 里还列出它的甘油菌（注明所在冻存盒）和用这个质粒制备的病毒 （见病毒）。它的地址里带着编号：12 号质粒是 …/plasmid/12。

看清序列里有什么

  • 元件库 （Feature library，在质粒页顶部有链接）按序列保存实验室的常用元件：启动子、ITR 和 LTR、 WPRE、抗性基因、标签等。在注释完整的图谱（比如来自 SnapGene 或 Addgene 的文件）上方点 加入元件库，就能把它有名称的特征保存进去； 管理员还可以 从所有质粒收集。在元件库页面用 从文件读取元件，可以直接从带注释的文件里提取—— 数据库给你的 GenBank、SnapGene .dna、厂家的图谱——一次可以传多个，也不必为每个文件建质粒。 元件库不预装任何元件：所有元件都来自你自己的文件，因为凭记忆写下的序列只要错一个碱基，就会让实验室里每一张图谱标注错误。 管理员还可以获取 常用元件包——约 1900 个元件，整理自约 2000 个常用质粒，点击后才从公开研究文献库下载 （约一分钟，下载完成后页面会显示）。它由作者导出某商业软件公开的元件库整理而成，重要的元件请自行核对； 你自己添加的元件始终优先。元件库支持按名称或序列搜索。在其他质粒上点 识别特征，就会标出元件库里每个元件所在的位置（正反链、跨越起点都能识别）， 原来的图谱保存在 版本 里。
  • 如果实验室自建服务器，管理服务器的人可以安装 pLannotate （一个独立的免费程序），图谱上方就会出现 用 pLannotate 注释。它通过序列比对来识别特征，而不是精确匹配，所以密码子优化过的基因、 相差一两个碱基的启动子也能找到，这些是元件库本身识别不到的。它标注的内容都保存在 版本 里，随时可以撤销。

构建新质粒

  • 组装质粒 （Assemble a plasmid，在质粒页顶部或任意图谱上方）用现有的质粒搭出下一个质粒。 在片段列表里按拼接顺序添加片段——整条质粒、它的某个特征、两个碱基之间的一段区域，或某个酶切后的片段—— 任何一个都可以反向，然后用三种方式组装：酶切连接 （用同样的酶切开，让黏性末端彼此配对）、Gibson / NEBuilder HiFi （相邻片段在接口处共用二十来个碱基；向导会设计补上这段同源的引物，并算出各自的 Tm） 或 Golden Gate （BsaI、BsmBI、BbsI 在识别位点之外切开，所以每个接口都是你选定的四碱基突出端）。 酶切时只列出在这条质粒上真正有位点的酶，并标明各有几个位点、单切点的排在前面； 选中的片段会画在它来源质粒的环形图上，让你在取用之前就看清切出来的是哪一段。 每个接口都会显示自己的碱基，并且只用一行说明哪里不对、是哪一端—— 片段 2 的 3′ 端与片段 3 没有重叠——而不是只说组装失败。 Golden Gate 在两个接口用了同一个突出端、某个突出端是另一个的反向互补、或某个突出端在两条链上读起来一样时会被拒绝， 因为这几种情况都会让片段有不止一种拼法。创建之前，你可以先看到产物的图谱、长度和其中的每个片段。创建质粒 之后得到的就是一个普通质粒：每个片段的特征都在新的位置上（被切开的特征保留还在的那一部分，并注明）， 每个片段都标在图谱上，便于看清接口；所有来源质粒连同用到的酶和坐标都写进 来源质粒，版本 里有它的第一条记录；如果勾选，还会标出元件库里的元件。 Gibson 的引物会保存到引物数据库并标为待订购， 同时画在各自扩增的那条质粒的图谱上，这样 复制以订购 也会一并带上它们。
  • 在图谱上画的引物（选中碱基后用 Edit → Create → Primer）也会保存到实验室的 引物数据库，状态为待订购，质粒 一列填着这个质粒。 图谱下方的 引物 卡片列出这个质粒的所有引物、各自的结合位置和 5′ 端尾巴；勾选几条后，复制以订购 （每行一条名称和序列，可直接粘贴到公司的下单页面）或 导出订购表 （CSV）。

试管、冻存盒与文件

  • 存放 标签页里的 文件 保存与这个质粒有关的东西：验证用的测序结果（.ab1）、 跑胶照片、厂家说明书，还可以用一句话写明这些文件是什么。图片会显示缩略图；添加者或管理员可以把文件移除。导出我的数据 时这些文件也会一并导出。
  • 每管都记录小提的 浓度 （Concentration，ng/µL）和 260/280，在表格里和 存放 标签页上都能看到， 该标签页还列出链接到它的实验记录本页面。

归属与批量操作

  • 归属 （Belongs to）：个人（Personal），或实验室公用（Lab common）——任何人都能编辑（共享的保种质粒），但只有负责人或 管理员能更改归属或删除它。Lab common 筛选标签会列出它们。
  • 选中质粒可以设置负责人、抗性或归属、移到某个冻存盒，或删除。移到另一个盒子但没指定 位置时，质粒会占用下一个空位。从 Excel 导入 （Import from Excel）可以把你原来的列表导进来。
