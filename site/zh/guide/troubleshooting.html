常见问题排查

常见问题和解决办法，每一条也放在相关的页面上。

应用在 Mac 上打不开
右键点它，选 打开 （Open）。如果 macOS 提示已损坏，先把它移到“应用程序”文件夹， 再试一次。 → 去相关页面
Linux：AppImage 没反应
给它加上可执行权限。如果还是启动不了，安装 libfuse2，或者改用 .tar.gz，运行 BioManager/BioManager。 → 去相关页面
手机连不上服务器
和管理员核对地址；确认你连的是实验室网络、VPN 或 Tailscale； 如果实验室用的是自己的证书，确认手机上已经安装。 → 去相关页面
我无法编辑某条记录
它属于别人，而且没有共享：BioManager 会告诉你是谁的。去问他，或者问管理员。 → 去相关页面
单元格变红了
那次修改没有保存；底部的消息会说明原因（必填项、不是有效日期的日期）。 → 去相关页面
批量修改出错了
设置 → 历史 （Settings → History）→ 撤销 （Undo）。 → 去相关页面
忘记密码
找管理员：在 设置 → 人员与权限 （Settings → People & access）里点你旁边的 ··· 就能重置。 → 去相关页面
新账号一直在等管理员批准
只有实验室的第一个账号是管理员，之后的账号要等它批准。在桌面版上，说明这台电脑上之前已经建过账号： 用那个账号登录。 → 去相关页面
这台电脑上的实验室没人能登录
在桌面版登录页点 新建实验室 （Start a new lab），会把原来的实验室移开（不删除任何东西）， 开始一个空的实验室；找回已搁置的实验室 （Bring back a lab set aside）可以撤回。 → 去相关页面
导入时有行被跳过
预览会按 Excel 里的行号逐一列出，并说明原因。改好那些行， 只导入它们：重新导入整个表格会把其他行再加一遍。 → 去相关页面
侧边栏里没有同事的数据库
那可能是他的个人数据库（图块上显示 Just you），只有 他本人和管理员能看到；也可能是管理员把它关闭了。 → 去相关页面
某个数据库从侧边栏消失了
可能是管理员在 设置 → 数据库 （Settings → Databases）里把它关闭了；数据会保留，重新开启后 就会回来。 → 去相关页面
其他问题
侧边栏里的 帮助 → 发送反馈 （Help → Send feedback，见下文），或者提交 issue—— 说明你用的是什么系统，以及你原本期望发生什么。
