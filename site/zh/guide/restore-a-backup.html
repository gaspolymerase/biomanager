怎么做

从备份恢复

把桌面版的实验室数据恢复原样：用你自己的备份，或 BioManager 在更新前留下的副本。

使用这台电脑的人桌面版
  1. 退出 BioManager。
  2. 打开它的数据文件夹：Mac 上是 ~/Library/Application Support/Biomanager/，Windows 上是 %APPDATA%\Biomanager\，Linux 上是 ~/.local/share/Biomanager/。实验室数据库是 data/biomanager.db。
  3. 把 data/biomanager.db 挪到稳妥的地方，不要删掉。
  4. 把备份放到原来的位置，命名为 biomanager.db。备份可以来自 Time Machine 或“文件历史记录”里这个文件夹的副本； 也可以是新版本改动数据库之前 BioManager 自动留下的副本 data/backups/before-upgrade-….db（保留最近十份）。 记录和页面里添加的文件在 uploads 文件夹里，也从同一份备份放回去。
  5. 打开 BioManager。如果是要撤销一次更新，用更新前的那个版本打开。

BioManager 打开的实验室就是做那份备份时的样子。

备份里没有之后的改动 做备份之后录入的一切都不在里面。确认无误之前，留着挪开的那个文件。
用“新建实验室”移开的实验室 找回已搁置的实验室 （Bring back a lab set aside，在 设置 → 实验室、登录页或新实验室的首页）会列出它们； 选一个后关闭 BioManager，下次打开时它就回来了。现在的实验室会被搁置在它的位置，所以可以用同样的方法撤回。它们保存在 data/old-labs/ 里。

实验室服务器

服务器每晚备份一次，每周恢复一次最新备份以证明备份可用。恢复只要一条命令，由负责服务器的人执行，而且不会删掉被替换的数据： 见服务器安装包里的 deploy/RUNBOOK.md 和保护数据安全。如果只是批量操作出了错， 用 设置 → 历史 → 撤销 就够了。

故障排除

BioManager 打不开，提示实验室数据库是空文件

这个文件是 0 字节，里面没有记录。按上面的步骤放回一份备份；或者删掉这个空文件，从一个新实验室开始。
