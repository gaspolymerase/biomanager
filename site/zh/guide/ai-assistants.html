数据与帮助

AI 助手

把你做了什么告诉 AI 助手；它提出记录，你在 BioManager 里批准。

实验室服务器或桌面版

BioManager 里面没有 AI。如果你已经在用某个助手（Claude、ChatGPT、Cursor、Cherry Studio 或其他支持 MCP 的应用）， 可以把它连到你的实验室。用你自己的话、或者拍一张实验记录本的照片告诉它你做了什么（102 号笼昨天产仔，7 只； 把两只老繁殖鼠从 88 号笼移到 91 号笼；今天早上给 TMX 组打了第 3 天的针），它会把这些变成记录：作为一个提议， 由你在 BioManager 里批准。它自己什么都不会改。

连接助手

打开帮助 → 连接 AI 助手（Connect an AI assistant；也在设置 → API 令牌里，以及空的修改提议页上）。 它会列出连接你的 BioManager 的几种方式，地址已经填好。都不用安装任何东西，只有在实验室网络里用 Claude Desktop 时例外（见下文）。

从 claude.ai、Claude 应用或 ChatGPT 连接

这些应用是从互联网访问 BioManager 的，所以实验室服务器要在互联网上：由管理员打开互联网访问（见服务器手册）。 之后连接页面会显示连接器地址，以 /api/v1/mcp 结尾。桌面版无法这样访问，请用下面的方式。

  1. 用这个地址把 BioManager 添加为自定义连接器。Claude：Settings → Connectors → Add custom connector （Team 或 Enterprise 套餐需要先由所有者添加）。ChatGPT：Settings → Connectors，开启开发者模式后， 新建一个使用 OAuth 的连接器。
  2. 要求连接时，会打开一个 BioManager 页面，要你输入连接码。在连接页面（在实验室网络里）按 获取连接码，把它输进去，再按允许。连接码只能用一次，10 分钟内有效。
  3. 这样就好了，网页版和手机应用都一样。这个连接会以应用的名字列在设置 → API 令牌里；在那里撤销就能断开。

从 Claude Code、Cursor、Cherry Studio 或 Claude Desktop 连接

这些应用运行在能连上 BioManager 的电脑上：桌面版就是同一台电脑，实验室服务器则是实验室网络里的任何电脑。 不需要互联网访问，也不需要懂连接是怎么回事：

  1. 让助手自己设置。在连接页面按复制这段话，发到与编程助手的对话里。这段话里有你的 BioManager 地址； 助手会自己添加 BioManager，然后告诉你怎么登录。
  2. 登录。在 Claude Code 里输入 /mcp 并选择 biomanager。BioManager 会在浏览器里打开， 问是否允许这个应用连接：按允许。不需要复制或保存令牌。
  • 想自己在 Claude Code 里设置，连接页面上也有要在终端里运行的那一条命令。
  • 对于不能登录的应用和 Claude Desktop，按生成令牌：它会生成一个读取和提议的令牌，下一页会给出每个应用 要复制的设置。Claude Desktop 运行 BioManager 源代码里的一个小程序 mcp/biomanager_mcp.py；步骤在 mcp/README.md 里。

使用

对它说：根据我的记录记下今天的工作：…… 它会查找你提到的每只动物、每个笼和每个实验，遇到可能对应 多条记录时问你，然后发一个提议并附上链接。

  • 助手能读取你能读取的内容，以你的身份。到设置 → API 令牌撤销它的令牌，就能切断它。

它能提议什么

  • 在小鼠、斑马鱼、果蝇和线虫以及其他物种数据库里：日常的记录。新的动物、笼、鱼缸和果蝇管；产仔、断奶、 移动和死亡；配对、卵批和转管；体重和读数；完成的计划任务。
  • 在实验里：完成一个步骤、观测指标、加入动物、实验状态、备注。
  • 在实验记录本里：在今天每日记录的日志里加一行，带时间。如果页面正开着，几秒钟内就会出现。
  • 它不能删除任何东西、签名，也不能改变谁能看到什么。
  • 它也能告诉你有哪些待办（和首页一样），并据此安排你的一天。

批准

提议到达时会通知你（铃铛），并在账户菜单的修改提议里等你。

  • 每个提议是一段用平实语言写的总结：每个数据库里会改什么，警告放在最上面（比如会被替换的产仔日期、 还太小不能断奶的幼仔）。查看每处修改列出每条记录修改前 → 修改后的内容。
  • 批准会一次完成所有修改；丢弃则一项都不改。不能逐项批准：如果有不对的地方，丢弃它， 让助手发一个改正后的提议。
  • 批准的提议在批量历史里是一批，标注着助手的名字，所以撤销能整体撤回（加到实验记录本里的那行会保留）。
  • 如果它涉及的记录在提议之后被改过，或者某项修改已无法完成，就什么都不会改，页面会说明是哪条记录、为什么。
  • 只有你能批准自己的提议，而且必须登录 BioManager：任何令牌都不行。没处理的提议会保留两周，然后过期。

故障排除

助手说连不上 BioManager

Claude Code、Cursor 或 Cherry Studio：确认 BioManager 正在运行，设置里的地址是它的地址（桌面版的地址在 设置 → API 令牌里），并且令牌没有被撤销或过期。claude.ai、Claude 应用或 ChatGPT：用不连实验室 Wi-Fi 的手机 打开连接器地址，确认能打开（应该显示一条要求 API 令牌的简短消息），并且地址以 /api/v1/mcp 结尾。

连接时说连接码不对

连接码只能用一次，10 分钟内有效。再按一次获取连接码，用新的连接码。

批准时说某条记录在提议之后被改过

有人（或你自己）在这期间改过它，提议可能已经过时。丢弃它，让助手重新提议。
