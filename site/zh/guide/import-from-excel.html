怎么做

从 Excel 导入

把实验室现有的表格原样导进来，不用模板，也不用改列名。

能添加记录的人所有数据库
  1. 导入小鼠前先建笼架：笼 → 笼架视图 → 新建笼架，名字和表格里一致。这样，带 Rack 和 Position 列的表格就能把每个笼放到对应位置；没有位置的会留在未放置里。
  2. 打开要导入的数据库，点表格上方工具栏里的从 Excel 导入（小鼠在小鼠标签页）。
  3. 选择文件（.xlsx、CSV 或 TSV，最大 15 MB、5,000 行），点继续。工作簿里有多个工作表时，在匹配结果上方选一个。
  4. 检查每一列对应到哪里。每个匹配都写了原因，任何一个都可以改。BioManager 没有的列，在库存或物种数据库里可以变成新列（如果你有配置权限），或者放进备注；选不导入则跳过。
  5. 表格里缺少的必填列（比如负责人），填一个值，所有行都用它。质粒和保种还要选每行是个人还是实验室公用。
  6. 点预览导入。每一行都会经过和数据库自身表单相同的检查，会被跳过的行按 Excel 里的行号列出来。修改对应返回上一步。
  7. 点导入按钮，上面会显示条数（比如导入 120 条小鼠记录）。

这些记录作为一个批次保存，可以在更多 → 批量操作记录里撤销。日期保持 Excel 的写法；读不出的日期， 或在未来的出生日期，会留空并保存在备注里。ID 已被占用的小鼠会拿到下一个空闲 ID，原来的 ID 记在备注里。

故障排除

导入时有行被跳过

预览会按 Excel 里的行号逐一列出，并说明原因。改好那些行，只导入它们：重新导入整个表格会把其他行再加一遍。
