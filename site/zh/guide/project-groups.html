实验室协作

项目组

在同一项目的成员之间共享动物、库存、数据库和页面。

1.0.3 起

项目组是实验室里做同一个项目的几个人：介于你个人和全实验室之间的一层。设置 → 人员与权限 → 项目组 （Settings → People & access → Project groups）列出所有项目组；打开一个，就能看到组里有谁、他们可以做什么。管理员创建项目组并命名； 管理员或项目组的组长（leads）添加和移除人员。一个人可以同时在多个项目组里。

项目组里的每个人是 组长 （Lead，管理项目组：添加和移除人员，设定组员可以做什么）、成员 （Member， 按项目组的开关行事）或 仅可查看 （Can only view，能看到与项目组共享的内容，但什么都不能改，适合轮转学生或合作者）。 只有管理员能把人设为组长。在 在这个项目组里，成员可以 （In this group, members may）下，组长或管理员可以选择：

  • 编辑项目组的动物和库存 （Edit the group's animals and stock，默认开启）；
  • 在项目组的数据库中添加和修改记录 （Add and change records in the group's databases，默认开启）：关闭后，组员在那里 只能查看，不能修改；
  • 在那里编辑彼此的记录 （Edit each other's records there，默认关闭）：关闭时，每个人只能编辑自己添加的记录；
  • 编辑与项目组共享的笔记本页面 （Edit notebook pages shared with the group，默认开启）：关闭后，以编辑权限共享给 项目组的页面只能查看；
  • 勾选完成项目组的待办 （Tick off the group's to-dos，默认开启）；
  • 把自己的东西与项目组共享 （Share their own things with the group，默认开启）：关闭后，只有组长能与项目组共享。

每一项的初始设置都和项目组一直以来的做法一样，所以在有人改动之前，什么都不会变。组长和管理员始终可以做所有这些事； 记录的负责人始终可以编辑自己的记录。

  • 与项目组共享。 凡是可以选共享（Shared）或实验室公用（Lab common）的地方，都会同时列出你的项目组：与某个组共享的繁殖 笼、质粒或试剂，组员可以在项目组允许的范围内编辑。繁殖缸或实验室保种果蝇管，在它的对话框里的 共享给 （Shared with）中 选择项目组。实验室其他人仍然能看到它们。
  • 项目组的数据库。 创建数据库时，给谁用？ （Who is it for?）会列出你的项目组：只有组员（和管理员） 能看到，组员会收到添加通知。数据库页面上的 与项目组共享 （Share with the group）可以把你自己的某个数据库交给一个项目组。
  • 项目组的日程和待办。 在日历上，谁能看到 （Who sees it）会列出你的项目组：组员会在 自己的日历上看到它（待办还会出现在首页），任何组员都可以勾掉待办；只有创建者或管理员能修改日程或 删除待办。
  • 实验记录本。 页面上的 共享 （Share）除了个人，也可以选项目组，权限为查看或编辑；模板也可以指定给某个项目组 （谁可以使用 （Who can use it））。
  • 鼠群。 “我的鼠群”旁边的 我的项目组 （My groups）显示你所在项目组所有成员的小鼠和笼。

删除项目组（管理员）后，原来共享给它的东西回到各自负责人名下（繁殖缸或保种果蝇管则按用途归实验室）， 项目组的数据库回到创建者名下。
