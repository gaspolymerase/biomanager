隐私

隐私。实验室的记录留在实验室。

BioManager 是实验室自己运行的软件。没有人运行一个保存你们记录的服务，所以要说的很少：全部都在这里。

实验室的记录

你们在 BioManager 里保存的一切（动物、库存、实验、实验记录本、成员账户）都保存在运行桌面版的电脑上，或实验室自己的服务器上。BioManager 的作者从不会收到这些内容，也没有 BioManager 账户或云端。

应用会发送什么

  • 每天一次的匿名计数。 为了让作者知道有多少实验室在用，每个安装每天发送几项计数和粗略信息：版本、桌面版还是服务器、操作系统类别和数据库类型；成员人数和一周内有修改的人数（都是区间）；打开了哪些功能；以及为这个安装随机生成的一个编号，让它只算一次。从不包含姓名、用户名、邮箱、任何人写的内容、数据库名称、服务器地址或电脑名称。数据发往 PostHog，并要求它不定位来源、不建立档案。管理员可以在 使用报告 里看到发送的确切内容并在那里关闭；服务器也可以用 BIOMANAGER_TELEMETRY=0 启动。
  • 检查更新。 应用向 GitHub 查询最新版本，只告诉它自己是哪个版本。
  • 实验室自己打开的功能。 用 Google、Microsoft 或学校账户登录；显示 Google 日历；通过实验室自己的邮件服务器发邮件；下载质粒特征库。每一项只向你选择的服务发送它需要的内容，而且只在实验室设置之后。

AI 助手和插件

BioManager 里面没有 AI。如果你连接了一个助手（Claude、ChatGPT 或其他），它以你的身份、按你的权限从你的 BioManager 读取实验室记录；它读到的内容由该助手的公司按你和他们的协议处理。你可以随时在 设置 → AI 助手与令牌 里断开连接。

给助手用的 BioManager 插件不收集、也不发送任何内容。它只是给助手的说明，在 Claude Code 里再加上你自己的 BioManager 地址。

本网站

biomanager.org 是静态网页，由 GitHub Pages 发布并经过 Cloudflare，它们的服务器会像任何网站主机一样看到每次访问。网站没有统计分析、没有广告，也没有 cookie。如果你选了语言，你的浏览器会在你自己的设备上记住它。在 GitHub 上提的问题和错误报告是公开的。

儿童

BioManager 是为在研究实验室工作的人做的，不面向儿童。
