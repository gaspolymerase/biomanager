    {# ---- 3. Address ---- #}

    {{ _('How people will reach it') }}

    1. {% trans %}In the Tailscale admin console → DNS, turn on MagicDNS and HTTPS Certificates.{% endtrans %}
    2. {% trans %}Under Settings → Keys, Generate auth key and paste it below. It is used once, to join the server, and isn't kept.{% endtrans %}
    3. {% trans %}After set-up, in Machines, open the server and Disable key expiry, or it drops off in 180 days.{% endtrans %}

    {% trans %}The address becomes biomanager.<your-tailnet>.ts.net, with a real certificate. Lab members install Tailscale (free for small teams), or you share the one machine with them.{% endtrans %}

    {% trans %}Before you start: the name's DNS record points at the server, and its firewall lets in ports 80 and 443. Let's Encrypt then issues the certificate by itself.{% endtrans %}
