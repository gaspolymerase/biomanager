## BioManager 2.13.1

### New

- **An AI assistant can set a sample type's prefix.** Tell it *give tissue the prefix B* (or *add plasma, numbered PL*) and it proposes it, saying which name the next sample of that type will get: *the next one left without a Sample ID is B523*. Changing an existing type's prefix is for an admin or whoever made the database, as in **Configure**; anyone who uses it may add a type. An empty prefix stops numbering a type.
  - **AI 助手可以设置样本类型的前缀。** 对它说 *给组织填前缀 B*（或 *添加血浆，按 PL 编号*），它会提出这项修改，并告诉你这一类型的下一个样本会是什么编号：*下一个不填样本编号的是 B523*。和 **配置** 里一样，修改已有类型的前缀只有管理员或这个数据库的创建者可以批准；用这个数据库的人都可以添加类型。前缀留空就不再给这一类型自动编号。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Desktop app**: *Install and Restart* when it offers 2.13.1, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  Nothing in the database changes. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
