## BioManager 1.5.7

### Fixed

- **On macOS 26, the window's close, minimise and zoom buttons are the size other apps' are** (14 points, not 12), and the app has the system's current look: its menus and the window's rounder corners. macOS kept the old look for BioManager because the app's launcher said it was built for an older macOS.
  - 在 macOS 26 上，窗口的关闭、最小化和缩放按钮与其他应用一样大，菜单和窗口圆角也是系统当前的样式。
- **With the sidebar collapsed, the window's buttons no longer hang over it.** The top row runs the width of the window, with the buttons at its left and your tabs after them; the sidebar's icons start below it.
  - 侧边栏收起时，窗口按钮不再压在侧边栏上：顶部一行横跨整个窗口，按钮在左侧，后面是标签页，侧边栏的图标从这一行下方开始。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.5.7, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Devices & copies → Updates → Update now**. It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  Nothing on a lab server changes from 1.5.6, and nothing in the database. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
