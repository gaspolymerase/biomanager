## BioManager 2.10.6

### Works differently

- **The loading animation comes sooner.** A page, or **Approve** on a proposal, that takes more than half a second now shows the small loading animation, so a wait of a second or so no longer looks as if BioManager has stopped. A page BioManager knows to be that slow on your computer shows it at once; one that opens within half a second still never flashes it. (In 2.10.4 it waited for a whole second.)
  - **加载动画出现得更早了。** 页面或在提议上按 **批准** 超过半秒，现在就会显示小的加载动画，等一秒左右也不会看起来像 BioManager 卡住了。BioManager 知道在你电脑上会这么慢的页面会立刻显示；半秒内打开的页面仍然不会闪一下。（2.10.4 里要等满一秒。）

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Desktop app**: *Install and Restart* when it offers 2.10.6, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  Nothing in the database changes. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
