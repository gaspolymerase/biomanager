## BioManager 2.10.5

### Works differently

- **Weigh a whole day from the keyboard.** In an experiment, **Weigh** (or **Measure**, **Count**) opens a box for every animal with the first one ready: type a weight and press **Enter** for the next, **Shift+Enter** to go back, and after the last one **Enter** saves them all. It shows how many are done ("12 of 30 entered") and ticks each one off. In the sheet's readout view the cells work the same way, as in a spreadsheet: **Enter** goes down to the next animal and each value saves as you leave it. **Weigh** is now a full button beside **Record manipulation**, and it becomes the main button while the sheet shows the readout.
  - **用键盘一口气录完一天的体重。** 在实验里，**称重** （或 **测量**、**计数**）会给每只动物一个输入框，第一只已经选好：输入体重后按 **回车** 到下一只，**Shift+回车** 回到上一只，最后一只之后再按 **回车** 全部保存。会显示录了多少（“已录入 12 / 30”），录完的打勾。表格的观测指标视图也一样，像电子表格：按 **回车** 到下一只，离开一格就自动保存。**称重** 现在是 **记录处理** 旁边的一个完整按钮，表格显示观测指标时它就是主按钮。

### Fixed

- **Bench mode's QR code shows again.** The **Bench mode** dialog showed a broken image where its QR code should be; it now shows the code to scan with a phone. A QR code opened on its own (`/labels/qr.svg`) had the same problem and is fixed too. Cage cards were not affected.
  - **实验台模式的二维码又能显示了。** **实验台模式** 对话框里本该是二维码的地方显示成一个坏掉的图片；现在会显示可以用手机扫的二维码。单独打开的二维码（`/labels/qr.svg`）也有同样的问题，一并修好了。笼卡不受影响。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Desktop app**: *Install and Restart* when it offers 2.10.5, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  Nothing in the database changes. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
