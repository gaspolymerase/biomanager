## BioManager 2.1.1

### Works differently

- **Litter born asks for the father too.** Beside the mother, type the father's mouse number or a note; **Genotyping** then fills in both from the litter it makes pups of, and the wean and genotyping reminders name them. Nothing in **Litter born** is required: a blank date is today, and every field can be filled in later.
  - **产仔时也记录父本。** 除了母本，还可以填写父本的小鼠编号或备注；之后 **基因型鉴定** 会从对应的窝自动填入父本和母本，断奶和基因型鉴定提醒里也会写出它们。**产仔** 里没有必填项：日期留空即为今天，每一项都可以以后再补。
- **Genotyping without a count.** Leave **Pups** empty and **Create litter** makes the litter now, with no pups yet: add them to it once they are counted. A count recorded at **Litter born** is filled in.
  - **不填数量也能基因型鉴定。** **幼崽数** 留空时，**创建窝** 会先建好这一窝，暂时不含幼崽，数清后再加入即可。**产仔** 时记录的数量会自动填入。
- **An assistant records the father too**, when it records a litter born, and the BioManager plugin (1.6.0) looks up the actions it uses before using them.
  - **AI 助手记录产仔时也会记下父本**，BioManager 插件（1.6.0）会先查阅要用的操作再使用。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Desktop app**: *Install and Restart* when it offers 2.1.1, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version adds a column (a litter's father) to the cage litters table; updating adds it, empty for every litter recorded before, and keeps everything else as it was. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
