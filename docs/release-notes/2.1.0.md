## BioManager 2.1.0

### New

- **Renumber an inventory.** An inventory record's **#** follows the order its rows came in, so after an import from Excel it rarely matches your own IDs. **•••** → **Renumber** (for the inventory's creator or an admin) gives every record the number in its name (*B12* becomes #12), or numbers them in the order of a column (B2 before B10). When a name has no number, or two records share one, it names them and changes nothing. It shows each # now and new before anything changes; notebook links (`@samples 12`), orders put into stock and an experiment's samples follow; printed labels keep the old # (their QR code still opens the record). It is one batch to undo in **Settings → History**.
  - **给库存重新编号。** 库存记录的 **#** 跟着导入时各行的顺序，所以从 Excel 导入后往往和你们自己的编号对不上。**•••** → **重新编号**（库存的创建者或管理员）会让每条记录的 # 等于名称中的数字（*B12* 成为 #12），或按某一列的顺序编号（B2 在 B10 之前）。有名称没有数字，或两条记录数字相同时，它会列出是哪些记录，什么也不改。改动之前会先列出每条的现编号和新编号；实验记录本里的链接（`@samples 12`）、已入库的订单和实验的样本会跟着变；已经打印的标签仍是旧编号（标签上的二维码仍能打开正确的记录）。可以在 **设置 → 历史** 里一次撤销。
- **An AI assistant fixes a notebook page in place.** Asked to correct a page, it changes that page rather than making another: its title, kind, tags, or its text, all of it or a few parts (a protocol's steps rewritten as a checklist, so **Run** can tick them off). You see each change before and after when you review the proposal; the text as it was is kept in the page's **History**. A signed page, or one someone has open, is left alone, and a page saved after the proposal was made is not overwritten.
  - **AI 助手会直接修正实验记录本的页面。** 让它改一页时，它会修改那一页，而不是再建一页：标题、类型、标签，或正文（全部或其中几处，比如把流程的步骤改写成清单，**运行** 模式就能逐项勾选）。审核提议时每处更改的前后你都能看到；原来的正文保存在页面的 **历史** 里。已签署的页面和有人正开着的页面不会被改；提议之后又保存过的页面也不会被覆盖。
- **An AI assistant files protocols.** It can make a folder in **Protocols**, put a protocol in it, and make a new page in a folder. It can also renumber an inventory, as above.
  - **AI 助手可以整理实验流程。** 它可以在 **实验流程** 里建文件夹、把流程放进去，新建页面时也可以放进某个文件夹。它也能像上面那样给库存重新编号。

### Works differently

- **An AI assistant sees every change it can propose.** Some assistant apps show only the start of a long tool description, so an assistant in Claude Code knew only the mouse changes: told "used 40 mg of tamoxifen", it guessed until it gave up. Now it is given a short list of every change, by area, and reads the ones it needs in full; a change it names wrongly is answered with the nearest ones.
  - **AI 助手能看到它可以提议的每一种更改。** 有些助手应用只显示很长的工具说明的开头，所以 Claude Code 里的助手以前只知道小鼠相关的更改：告诉它"用了 40 mg 他莫昔芬"，它会一直猜到放弃。现在它会先拿到按领域列出的全部更改的简短清单，再完整读取要用的那几种；名称说错时会告诉它最接近的几种。

### Updating

- **Desktop app**: *Install and Restart* when it offers 2.1.0, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
