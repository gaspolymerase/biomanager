## BioManager 2.0.9

### New

- **Changing a rack's layout asks what happens to the cages in it.** A cage's place is kept as a row and a column, and the rack's layout gives it its name. So changing a rack's rows, columns or how its positions are named could rename the places of cages nobody had moved: swap letters and numbers, and the cage at F7 read G6. Now, before saving such a change, BioManager lists every cage it touches, with its position now and after each choice, and asks: **Keep each position name** (F7 stays F7 and moves to the cell that is called F7 now; chosen first when the naming changed) or **Keep each in the same cell** (its row and column stay and its name changes). A cage the new layout has no place for stays in its rack with no position, under **Unplaced**. The dialog counts these cages, and any position that would hold more than one cage with living mice. **Cancel** saves nothing. Renaming a rack or making it bigger asks nothing. The change and the moves are one batch, so **Batch history** can undo them together. Fish racks, fly and worm racks, inventory boxes and plasmid boxes ask the same. Shrinking a box or rack past what it holds is now this same question instead of being refused.
  - **修改笼架布局时，会先问笼怎么处理。** 笼的位置记的是第几行、第几列，位置的名称由笼架的布局决定。所以修改笼架的行数、列数或位置编号方式时，没有被移动的笼的位置名称也可能变：把字母和数字对调，原来在 F7 的笼会显示成 G6。现在保存这样的修改之前，BioManager 会列出受影响的每个笼，以及它现在的位置和每种选择之后的位置，并问你：**保留各自的位置名称**（F7 仍是 F7，移到现在叫 F7 的格子；编号方式改变时默认选这个），或 **各自留在原来的格子**（行和列不变，名称随之改变）。新布局里放不下的笼会留在原笼架上，但没有位置，出现在 **未放置** 里。对话框会数出这些笼，以及会放有不止一个有活鼠的笼的位置。点 **取消** 就什么都不保存。只改笼架的名称或把笼架变大，不会询问。修改和移动是同一批操作，可以在 **批量操作记录** 里一起撤销。鱼缸架、果蝇和线虫的架子、库存冻存盒和质粒盒也一样会询问。把冻存盒或架子缩小到放不下里面的东西时，也改为问同样的问题，不再拒绝。
- **The API can read and change cage racks**: `GET /api/v1/racks`, and `PATCH /api/v1/racks/<name>`. A change that would rename or leave out cages' places needs `"cages": "keep_names"` or `"keep_cells"`. Without one, the answer is 409, with what each choice would do.
  - **API 可以读取和修改笼架**：`GET /api/v1/racks` 和 `PATCH /api/v1/racks/<name>`。会改变或去掉笼的位置的修改，需要带上 `"cages": "keep_names"` 或 `"keep_cells"`。没有带的话会返回 409，并说明每种选择的结果。

### Updating

- **Desktop app**: *Install and Restart* when it offers 2.0.9, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  The database is unchanged in this release. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
