## BioManager 2.13.2

### Fixed

- **The loading animation moves in the Mac app and Safari.** While a page or a proposal took a while, the small loading animation stood still there, as if BioManager had stopped. It now keeps moving until the next page comes, as it always did in Chrome, Edge and the Windows app. The well plate, the tenth of the animations, never came up before; now it does, and each window never shows the same one twice in a row.
  - **在 Mac 应用和 Safari 里，加载动画会动了。** 页面或提议要等一会儿时，那里的小加载动画之前一直定住不动，看起来像 BioManager 卡住了。现在它会一直动到下一页出现，和在 Chrome、Edge 和 Windows 应用里一样。十个动画里的孔板以前从来不会出现，现在也会出现了；同一个窗口里也不会连续两次出现同一个动画。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Desktop app**: *Install and Restart* when it offers 2.13.2, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  Nothing in the database changes. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
