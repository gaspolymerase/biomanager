## BioManager 2.10.1

### New

- **Run mode shows the table written under a step.** Put a table (`/table`) after a checklist step and before the next one, such as the master mix for that step, and **Run mode** shows it with that step at the bench. A heading ends it, so a Samples or Results table stays out. The table is shown as it reads in the page; change it in the page.
  - **执行模式会显示写在某一步下面的表格。** 在检查清单的某一步之后、下一步之前放一个表格（`/table`），比如这一步的反应体系，在实验台前用 **执行模式** 时它会和这一步一起显示。遇到标题就停止，所以样品表和结果表不会被带进来。表格按页面里现在的内容显示，要修改请回到页面里改。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Desktop app**: *Install and Restart* when it offers 2.10.1, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  Nothing in the database changes. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
