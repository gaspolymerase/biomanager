## BioManager 2.0.6

### Works differently

- **Inventories open sooner in Chrome, Edge, the Windows app and on Android.** An inventory's cells (Reagents, Samples, Antibodies and the others) are now drawn as plain text, and each becomes its box or menu the moment you click, tap or Tab to it. They look and work as before: the cursor lands where you clicked, a menu opens its list, **Box** and **Position** open together, and pasting a column from a spreadsheet fills the rows below. These browsers read every box on a page as it opens, so fewer boxes means a shorter wait: a sheet opens a fifth to a third sooner (about 400 samples in 2.8 seconds instead of 3.5 to 3.9; 200 in 1.75 instead of 2.15). Search, sorting, **Export** and **Print** give the same results as before. Safari and the Mac app are unchanged.
  - **在 Chrome、Edge、Windows 版和 Android 上，库存表打开得更快。** 库存表（试剂、样本、抗体等）的单元格现在先显示为普通文字，点击、轻触或按 Tab 进入时才变成输入框或菜单。外观和用法都和以前一样：光标落在点击的位置，菜单会展开选项，**冻存盒** 和 **位置** 一起打开，从表格软件粘贴一列也会依次填入下面的行。这些浏览器打开页面时会读一遍每个输入框，输入框少了，等待就短了：表格打开快五分之一到三分之一（约 400 个样本从 3.5～3.9 秒缩短到 2.8 秒；200 个从 2.15 秒缩短到 1.75 秒）。搜索、排序、**导出** 和 **打印** 的结果和以前一样。Safari 和 Mac 版不变。

### Fixed

- **A status the app set itself no longer shows blank.** When a save changed another menu in the same row, for example setting a quantity below **Low at**, which turns the status to *low*, that menu showed an empty choice until the page was reloaded. It now shows the new value at once, on every sheet.
  - **应用自动设置的状态不再显示为空白。** 保存时如果同一行里的另一个菜单也被改动（例如数量低于 **低库存线** 时状态自动变为 *低*），那个菜单以前会一直显示空白，直到刷新页面。现在会立即显示新的值，所有表格都是如此。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first. This is the update that matters for this version: the pages come from the server, so a desktop app or phone joined to a lab's server opens inventories faster once the server is on 2.0.6.
- **Desktop app**: *Install and Restart* when it offers 2.0.6, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
