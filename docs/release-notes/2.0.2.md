## BioManager 2.0.2

### Works differently

- **A long inventory opens in a few seconds.** An inventory listing more than 500 entries now opens with its first page, and each other page comes as you turn to it, in about a second. Search, sorting, the buttons above the sheet and its count still go by every entry, as before. In a lab with about 5,000 reagents, in Chrome: 11 s in 2.0.1, under 3 s now (23 s before 2.0.1). **Export** and **Print** fetch every row first, a few seconds for thousands of entries.
  - **很长的库存表几秒钟就能打开。** 超过 500 条记录的库存表现在打开时只有第一页，翻到其他页时再载入那一页，大约一秒。搜索、排序、表格上方的筛选按钮和计数仍和以前一样按全部记录来算。在有约 5,000 条试剂的实验室里，用 Chrome：2.0.1 要 11 秒，现在不到 3 秒（2.0.1 之前要 23 秒）。**导出** 和 **打印** 会先载入所有行，几千条记录要几秒钟。
- **Turning the pages of a long sheet stays quick.** On a sheet of thousands of rows (mice, tanks, vials), the pages you had turned past stayed on the page, hidden, and every later search or sort slowed down with them. Now only the page you see is there; rows you've ticked stay ticked.
  - **长表格翻页依然很快。** 在有几千行的表格里（小鼠、鱼缸、果蝇管），翻过的页以前会隐藏着留在页面上，之后每次搜索或排序都会因此变慢。现在页面上只有你看到的那一页；勾选的行仍保持勾选。
- **The samples sheet's Custom tag** follows your choice on the mouse sheet again: hidden there, it is hidden here too.
  - **样本表的自定义标记** 又会跟随你在小鼠表上的选择：在那里隐藏，这里也隐藏。

### Updating

- **Desktop app**: *Install and Restart* when it offers 2.0.2, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
