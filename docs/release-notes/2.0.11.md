## BioManager 2.0.11

### Works differently

- **Empty cages stay out of Unplaced.** On **Cages → Rack grid**, the **Unplaced** list beside the rack now holds only the cages with living mice that have no position yet, so the ones you still have to put on a shelf aren't buried among empty cages. When empty cages are left out, a line under the list says so; the cage sheet still lists them, as before. Dragging an empty cage off the rack onto **Unplaced** takes it out of the rack as before; it then shows only in the sheet.
  - **空笼不再列在“未放置”里。** 在 **笼 → 笼架视图** 里，笼架旁的 **未放置** 列表现在只列出有活鼠、还没有位置的笼，需要放上架子的笼不会再淹没在空笼里。有空笼没列出时，列表下方会有一行说明；笼表格仍和以前一样列出它们。把空笼从笼架拖到 **未放置**，仍和以前一样把它移出笼架，之后它只在表格里显示。

### Updating

- **Desktop app**: *Install and Restart* when it offers 2.0.11, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  The database is unchanged in this release. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
