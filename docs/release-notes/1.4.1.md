## BioManager 1.4.1

### Fixed

- **A lab server built from the source code sends its anonymous daily counts again.**
  - A server whose app was built from a copy of the source (`docker compose up -d --build` in a checkout) stopped sending them in 1.2.0, even when they were switched on. They are how BioManager's makers know how many labs use it.
  - They hold counts only: how many members and how many were active, as ranges, and which databases are on; never a name or anything anyone wrote. The **Usage report** (**Help → Feedback**) shows exactly what is sent, and **Switch off** stops it.
  - Servers installed from the release bundle, and the desktop app, were never affected.

### Updating

- **Desktop app**: nothing changes for the desktop app; *Install and Restart* when it offers 1.4.1, or keep 1.4.0.
- **Lab server built from the source**: `git pull`, then `docker compose up -d --build` in `deploy/`.
- **Lab server from the release bundle**: nothing changes; update when convenient (**Settings → Devices & copies → Updates → Update now** on 1.2.6 or later).

  This version changes nothing in the database.
