## BioManager 2.10.3

### Fixed

- **Reading lists every paper.** A library brought in from Zotero (a thousand papers or more) now shows in full: before, Reading listed only the 500 most recently changed, and its search looked only at those. The number of papers is shown beside the title, a hundred or so at a time with **Show more** below. With the picture view chosen, papers that have no pictures yet are still listed as cards under it, instead of the page looking empty. ([#142](https://github.com/gaspolymerase/biomanager/issues/142))
  - **文献会列出所有论文。** 从 Zotero 导入的文献库（一千多篇也一样）现在会全部显示：以前文献页只列出最近修改的 500 篇，搜索也只查这些。标题旁显示篇数，每次先显示一百多篇，下面的 **显示更多** 显示其余的。选了图片视图时，还没有图片的论文仍会以卡片列在下面，页面不会看起来是空的。
- **A received order can go into a list of the lab's own.** **Add it to stock?** now offers the lists a lab made with **Custom list** beside reagents, chemicals, antibodies and viruses, so petri dishes go into **Consumables** (or 耗材); a consumable or equipment order picks the list named for it. The order and the new item link to each other, as with reagents. ([#144](https://github.com/gaspolymerase/biomanager/issues/144))
  - **到货的订购可以加入实验室自建的列表。** **加入库存吗？** 现在除了试剂、化学品、抗体和病毒，还会列出用 **自定义列表** 建的列表，培养皿就能进 **耗材**；耗材或仪器设备类的订购会默认选名字对应的列表。订购和新记录会互相链接，和试剂一样。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Desktop app**: *Install and Restart* when it offers 2.10.3, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  Nothing in the database changes. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
