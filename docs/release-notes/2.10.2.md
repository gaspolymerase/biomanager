## BioManager 2.10.2

### New

- **Run mode shows everything written for a step.** At the bench, each step now comes with what you wrote for it, as it reads in the page: its sub-bullets and notes (a "make sure the tissue is covered" under the step), sub-steps, and the table, picture, quote, callout or calculator written after it and before the next step, such as the master mix for that step. A heading or a line (`---`) ends a step's reach, so the Results table and the Notes stay out. It is shown read-only; change it in the page, and Run mode follows.
  - **执行模式会显示为某一步写的所有内容。** 在实验台前，每一步都会带上你为它写的内容，和页面里看到的一样：它下面的小点和备注（比如步骤下的"确保组织被浸没"）、子步骤，以及写在它之后、下一步之前的表格、图片、引用、提示框或计算器，比如这一步的反应体系。遇到标题或分隔线（`---`）就停止，所以结果表和备注不会被带进来。这里只能查看；要修改请回到页面里改，执行模式会随之更新。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Desktop app**: *Install and Restart* when it offers 2.10.2, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  Nothing in the database changes. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
