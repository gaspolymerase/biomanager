## BioManager 2.0.3

### Works differently

- **The desktop app talks to your lab's server faster.** An app that has joined a lab's server used to open a new secure connection for every page, every script and every save, each one a few round trips to the server before anything was asked. It now keeps its connection open and uses it again. On a campus network that saves a few hundredths of a second a request; on a server further away, or over a VPN, a few tenths: every cell you edit saves sooner, and a page with several parts comes quicker.
  - **桌面应用和实验室服务器之间更快了。** 加入了实验室服务器的应用以前每打开一页、每载入一个脚本、每保存一次都要新建一条安全连接，每条都要先和服务器往返几次才开始请求。现在连接会一直保持并反复使用。在校园网里每个请求能省几十毫秒；服务器离得远或走 VPN 时能省零点几秒：每改一个单元格都保存得更快，由几部分组成的页面也来得更快。

### Updating

- **Desktop app**: *Install and Restart* when it offers 2.0.3, or download it below. Your data is kept outside the app. This is the update that matters for this version: the change is in the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
