## BioManager 2.0.13

### Works differently

- **Sheets are ready sooner once they arrive.** The browser restyled every cell of a sheet several times while it opened; it now does so about once. The **Mice**, **Cages**, **Litters**, inventory and fish sheets are ready to use a quarter to nearly half sooner once the page has arrived: in a large lab, the browser's part of opening the mice goes from about 0.6 to 0.37 seconds, and of an inventory from about 0.8 to 0.45. Nothing looks different.
  - **表格到达后更快可用。** 以前浏览器在打开表格时要把每个单元格的样式重算好几遍，现在大约只算一遍。**小鼠**、**笼**、**窝**、库存和斑马鱼表格在页面到达后快四分之一到近一半可用：在一个大实验室里，浏览器打开小鼠表格的时间从约 0.6 秒降到 0.37 秒，库存表格从约 0.8 秒降到 0.45 秒。外观没有任何变化。
- **The Cages tab and Cage cards ask the server for less.** As the **Mice** tab does since 2.0.12, they read only the cages the chosen view (**My colony**, **My groups**, **Shared**) can list, not every cage in the lab: in a large lab the server answers the **Cages** tab in 0.8 seconds instead of 1.4.
  - **笼表格和笼卡向服务器要的数据更少。** 和 2.0.12 起的 **小鼠** 表格一样，只读取当前视图（**我的鼠群**、**我的项目组**、**共享**）能列出的笼，而不是实验室的所有笼：在一个大实验室里，服务器应答 **笼** 表格的时间从 1.4 秒降到 0.8 秒。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first. The pages come from the server, so a desktop app or phone joined to a lab's server gets the faster sheets once the server is on 2.0.13.
- **Desktop app**: *Install and Restart* when it offers 2.0.13, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
