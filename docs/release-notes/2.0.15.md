## BioManager 2.0.15

### Works differently

- **The Cages tab comes from the server sooner.** Its rows, each cage's mice and their buttons are written in a quarter of the time, and the cages it does not draw are read more lightly: in a large lab (100,000 mice) the server answers the **Cages** tab in about 0.25 seconds instead of 0.33 to 0.39. Nothing looks different.
  - **笼表格从服务器来得更快。** 表格的行、每个笼的小鼠和按钮只用原来四分之一的时间写出，不显示的笼也读得更轻：在一个大实验室（10 万只小鼠）里，服务器应答 **笼** 表格的时间从 0.33 到 0.39 秒降到约 0.25 秒。外观没有任何变化。

### Updating

- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first. The pages come from the server, so a desktop app or phone joined to a lab's server gets the faster sheet once the server is on 2.0.15.
- **Desktop app**: *Install and Restart* when it offers 2.0.15, or download it below. Your data is kept outside the app.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
