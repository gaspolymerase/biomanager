## BioManager 2.0.4

### Works differently

- **A cage purpose shows the cages in use.** Above the cages, **Breeder**, **Breeding** and **Experiment** (and any purpose your lab added) now show only that purpose's cages that still hold living mice, in the table and in **Cards**, and the number on each button counts only those. Old, empty cages no longer fill the list when you pick a purpose; **All** still shows them.
  - **按用途筛选时只显示在用的笼。** 笼列表上方的 **种鼠笼**、**繁殖** 和 **实验**（以及实验室自己加的用途）按钮，现在在表格和 **卡片** 里都只显示该用途下还有活鼠的笼，按钮上的数字也只算这些笼。选用途时，以前的空笼不会再挤在列表里；点 **全部** 仍能看到它们。

### Updating

- **Desktop app**: *Install and Restart* when it offers 2.0.4, or download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Version → Update now** (before 1.7.5, **Settings → Devices & copies → Updates**). It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  This version changes nothing in the database's tables. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
