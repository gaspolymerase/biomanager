## BioManager 1.5.5

### New

- **Stock as a number, with a Low at level** ([#58](https://github.com/gaspolymerase/biomanager/issues/58)). Reagents, chemicals, antibodies, viruses and primers have a **Low at** column next to Quantity. Write the quantity as a number (12, 2.5 or 2,5) and when it falls to that level the status turns *low* by itself, and the item's owner gets one notice; at 0 it turns *empty*. Raise the quantity again and it goes back to *in stock*. A quantity written in words is left as it is. Home's **Expiring & low stock** now shows how much is left.
  - 库存可以写成数字，并设一个 **低库存线**：数量降到这个数时，状态自动变为低库存，并提醒它的主人；降到 0 时变为空。
- **Put the important columns first** ([#58](https://github.com/gaspolymerase/biomanager/issues/58)). Drag a column's header left or right on any sheet; the order is remembered for you, and **Columns → Reset column order** brings the default back. With the keyboard, the **Columns** menu has arrows to move each column. An admin sets the order the whole lab starts with in the database's **Configure** (Move up / Move down); organism databases have the same arrows in **Settings → Fields**.
  - 任何表格都可以拖动列标题调整列的顺序，按人记住；管理员可以在 **配置** 里设定全实验室默认的顺序。
- **Find saved primers** ([#62](https://github.com/gaspolymerase/biomanager/issues/62)). A plasmid's **Primers** card has a **Find saved primers** switch: it looks through every primer the lab has saved and lists those that bind this plasmid, where and in which direction, as an exact match or with a 5′ tail, so nobody orders a primer the lab already has. **Show on map** draws them on the map to look at; they are not saved into the plasmid. A glycerol stock's map has the same switch.
  - 质粒的 **引物** 卡片新增 **查找已有引物** 开关：列出实验室已保存的、能结合这条序列的引物，以及位置和方向，避免重复合成；**在图谱上显示** 只用于查看，不会存进质粒。

### Fixed

- **A lab server taking in a lab could stop with “app_settings: 12 read, 13 written”** and change nothing, when its daily update check happened to run at the same moment. It happened only on a PostgreSQL server.
  - 实验室服务器接收桌面版的实验室时，偶尔会报错“app_settings: 12 read, 13 written”而不做任何更改；现在修好了。

### Updating

- **Desktop app**: *Install and Restart* when it offers 1.5.5, or download it below. A Mac app on 1.5.2 or earlier may not offer it (fixed in 1.5.3): download it below. Your data is kept outside the app.
- **Lab server on 1.2.6 or later**: **Settings → Devices & copies → Updates → Update now**. It backs up first.
- **Lab server on an earlier version**, by hand:
  1. Take a fresh backup (`docker compose exec backup backup.sh`).
  2. Unpack the new `biomanager-server.tar.gz` over the old folder. Your `.env`, backups and certificates are kept.
  3. Run `host/load-image.sh`, then `docker compose up -d --build`.
  4. Run `sudo host/install.sh`, which sets up **Update now** for next time.

  The database gains one column (an item's Low at level), added on start; nothing else changes. Details are under *Updating the app* in the runbook (`deploy/RUNBOOK.md` in the bundle).
