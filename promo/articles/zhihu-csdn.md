# 研究生自己写了个免费开源的实验室管理软件：小鼠、质粒、试剂和实验记录，一个软件管好

我是做生物实验的研究生。组里的小鼠表一人一个版本，笼卡是手写的，换个笼就对不上；质粒在哪个冰箱哪一盒，全靠记忆；试剂用完了才发现没人订；有人毕业了，几年的数据散在二十个 Excel 文件里。

市面上的实验室管理软件要么很贵，要么只管一样东西，要么数据得放在别人的服务器上。所以我自己写了一个：**BioManager**，免费、开源（MIT 协议），没有付费版，数据只存在你自己的电脑或实验室自己的服务器上。

官网和下载：https://biomanager.org/zh/

## 它能管什么

**动物和物种**

- **小鼠**：笼位、窝、断奶日期（记一窝出生，P21 断奶日期自动算好）、繁殖笼、基因型鉴定。机架视图里拖一拖就给笼子换位置。
- **斑马鱼、果蝇、线虫**都有自己的数据库。果蝇的翻管提醒按温度算：25 °C 每 14 天，18 °C 每 28 天。
- 其他物种（爪蟾、蝾螈……）可以自己建数据库：选个模板，或者勾选它需要的字段，不用写代码。

![小鼠表：像 Excel 一样直接改](mice.jpg)

**分子生物学和库存**

- **质粒**：导入 GenBank、FASTA 或 SnapGene 文件，序列和 feature 都保留，有可以编辑的交互式图谱；每一管都有位置，冰箱哪盒哪格一查就知道。
- **样本、试剂、抗体、病毒、引物、细胞系**，每样东西都知道自己放在哪里。
- **订单**：申请 → 已订 → 到货。到货时拖一下卡片，就能直接入库，供应商、货号、批号都已经填好。

![质粒图谱](plasmid-map.jpg)

**记录和安排**

- **实验记录本**：页面里提到一只鼠，就链接到它，鼠的基因型和笼号直接显示在旁边；页面可以签名。
- **数据表**：从 Excel 粘贴数据，直接出柱状图、散点图、箱线图，带误差线和 t 检验、Mann–Whitney 或 ANOVA，可导出 SVG/PNG。
- **日历**：断奶、实验、订单都排在上面，全组共享。
- **给药计算**：按每只鼠最新的体重算剂量和体积，每天提醒，体重曲线上组间差异自动标星号，可导出给 Prism 或 R。

**手机和 AI**

- 打印带二维码的笼卡（也支持 Brother、Zebra 标签机），站在鼠架前用手机一扫，就打开这只笼子，可以直接记一笔。
- 拍一张实验记录本的照片，或者打一句话，发给你常用的 AI 助手（Claude、ChatGPT 等）。它读懂你的笔记，找到对应的笼子和小鼠，在 BioManager 里整理成一份提议；你点批准，记录才写进去。

## 从 Excel 搬过来

原来的 Excel 表直接导入，列名按意思匹配：DOB、Born 都认得是出生日期，Cage # 就是笼号，Male、m、♂ 都会变成 M。先预览再导入，哪一行会被跳过、为什么，都按 Excel 的行号写清楚。整批导入可以一键撤销；平时每一次改动也都有记录，改错了能撤销。

## 怎么用

- **一个人用**：下载桌面版（Mac / Windows / Linux），打开就能用，第一个注册的账号就是管理员。
- **全组一起用**：在实验室的一台电脑、NAS 或云服务器上搭一个服务器，每人一个账号，手机浏览器也能打开。桌面版里有向导，一步步帮你搭。
- **中文界面**：设置里可以切换中文和英文。
